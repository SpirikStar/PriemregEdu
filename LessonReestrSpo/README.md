# Извлечение тематического плана ПМ из DOC-файла реестра СПО

## Назначение проекта

Проект автоматизирует извлечение структурированной информации из документов реестра ПОП СПО (reestrspo.firpo.ru).

**Цель:** по заданному URL страницы реестра (https://reestrspo.firpo.ru/reestr-pop-spo/reestr-pop-spo/reestr-pop-spo_3739.html) и названию дисциплины получить JSON-объект вида:

```json
{
  "Название_темы": {
    "Содержание": {
      "1": "...",
      "2": "..."
    }
  }
}
```

**Ключевые сложности:**

1. В документе может быть несколько оглавлений и несколько таблиц с похожими названиями.
2. В одном направлении подготовки может быть несколько дисциплин — нужно выбрать таблицу именно для указанной.
3. Формат файла — `.doc` (не `.docx`), что требует предварительной конвертации.
